# forTime 안드로이드 앱

저장소 하나로 웹과 앱을 함께 관리합니다. 이 `app/` 폴더만 앱 전용이고, 나머지(`src/`, `public/`, `build.mjs`, `site.config.mjs`)는 사이트와 앱이 같이 씁니다.

| 수정한 곳 | 사이트 (fortime.kr) | 앱 |
| --- | --- | --- |
| `src/`, `public/` (운세 문장, 화면, 디자인) | GitHub에 올리면 Cloudflare가 자동 배포 | 다음 앱 빌드 때 자동 포함 → 플레이 스토어 업데이트 |
| `app/` (앱 설정, 광고, 아이콘) | **영향 없음** (Cloudflare는 이 폴더를 빌드하지 않음) | 다음 앱 빌드 때 반영 |
| `site.config.mjs` (애드센스 등) | 반영 | 앱은 애드센스를 쓰지 않음 |

사이트는 올리는 즉시 바뀌지만, 앱은 새 버전을 만들어 플레이 스토어에 올려야 사용자에게 반영됩니다.

## 앱에서 달라지는 점 (사이트 코드는 그대로, 앱에서만 덧붙임)

- **광고:** 애드센스는 앱에서 쓸 수 없어서 다음처럼 바뀝니다.
  - 페이지 안의 광고 자리는 숨기고, 화면 하단에 AdMob 배너 1개를 고정해서 띄웁니다. 하단 탭은 배너 위로 올라가고, 키보드가 열리면 배너가 잠시 숨겨집니다.
  - "광고 보고 열기"(해운정사·하나·도한·궁합·사주·2027)는 AdMob 보상형 광고로 바뀝니다. 광고를 끝까지 봐야 열리고, 광고를 불러오지 못하면 사이트와 같은 규칙대로 그냥 열립니다.
  - 유럽 등 동의가 필요한 지역에서는 구글 동의 창이 먼저 뜹니다.
- **서버 기능:** 게시판·문의·위치·통계는 fortime.kr의 `/api`를 그대로 씁니다.
- **공유:** 공유 링크와 카드에 찍히는 주소는 `https://fortime.kr`로 나갑니다. 공유는 안드로이드 공유 창을 씁니다.
- **기타:** 뒤로가기 버튼을 누르면 열린 창부터 닫고, 그다음 이전 화면으로 갑니다. 첫 화면에서 누르면 앱이 종료됩니다. 화면은 세로로 고정됩니다.
- **제외되는 파일:** 검색엔진용 파일(sitemap, robots), 워커, OG 이미지는 앱에 넣지 않습니다.

## 처음 한 번 준비

1. [Android Studio](https://developer.android.com/studio)를 설치합니다(JDK 포함).
2. [Node.js](https://nodejs.org) 22 이상을 설치합니다.
3. 터미널에서 다음을 실행합니다.
   ```bash
   cd app
   npm install
   ```

## 앱 만들기 · 휴대폰에서 실행

```bash
cd app
npm run sync      # 사이트 빌드 → 앱용 변환(www/) → 안드로이드 프로젝트에 복사
npm run open      # Android Studio 열기 → 휴대폰 연결 후 ▶ 실행
```

사이트 소스를 고친 뒤에도 `npm run sync`만 다시 실행하면 됩니다.

## 출시 전 할 일

1. **AdMob 실제 ID로 바꾸기:** admob.google.com에서 앱(Android)을 추가하고, 광고 단위 2개(배너, 보상형)를 만듭니다. 받은 ID를 `app/app.config.mjs`의 `admob`에 넣고 `test: false`로 바꾼 다음 `npm run sync`를 실행합니다.
   - 실제 ID로 개발하는 중에 광고를 직접 누르면 계정이 정지될 수 있습니다. 테스트는 테스트 ID로 하세요.
2. **AdMob 확인 파일(app-ads.txt) 올리기:** AdMob에서 안내하는 app-ads.txt를 fortime.kr 루트에 올려야 합니다. 사이트 쪽 작업이므로 사이트 대화에서 진행하세요.
3. **서명된 번들 만들기:** Android Studio → Build → Generate Signed App Bundle 순서로 `.aab` 파일을 만듭니다.
   - 키스토어(.jks)와 비밀번호는 잃어버리면 업데이트를 못 하니 꼭 따로 보관하세요.
   - 키스토어는 GitHub에 올리지 마세요.
4. **플레이 콘솔 등록:** 개발자 등록비는 1회 25달러입니다. 개인정보처리방침 주소로 `https://fortime.kr/ko/privacy/`를 쓰면 됩니다. 데이터 보안 항목에는 "광고 ID 사용(AdMob)"을 표시하세요.

## 버전 올리기

`android/app/build.gradle`의 `versionCode`(1, 2, 3…)와 `versionName`(1.0, 1.1…)을 올린 뒤 번들을 다시 만듭니다.
